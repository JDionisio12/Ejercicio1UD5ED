# Proyecto Ejercicio1UD5ED - Documentación Javadoc y Control de Versiones

Este repositorio contiene la resolución del ejercicio práctico de la **Unidad Didáctica 5** para el módulo de **Entornos de Desarrollo**. El objetivo principal es demostrar el dominio de la generación de documentación técnica y el uso de herramientas de control de versiones distribuidas (Git).

##  Descripción del Proyecto
El proyecto consiste en una aplicación Java que implementa una jerarquía de clases basada en animales. Se han aplicado los siguientes conceptos:
* **Programación Orientada a Objetos**: Uso de interfaces y herencia.
* **Documentación Javadoc**: Generación de archivos HTML detallando clases, métodos y parámetros.
* **Gestión con Git**: Configuración de un repositorio remoto en GitHub y sincronización desde el IDE NetBeans.

##  Tecnologías Utilizadas
* **IDE**: Apache NetBeans
* **Lenguaje**: Java 
* **Control de Versiones**: Git & GitHub
* **Autenticación**: Personal Access Tokens (Classic)

##  Estructura del Repositorio
* `/src`: Contiene el código fuente del proyecto (`Animal.java`, `Perro.java`, `Gato.java`, etc.).


##  Cómo se ha configurado
Para la subida de este proyecto, se ha vinculado el repositorio local con la URL remota de GitHub. Debido a las políticas de seguridad actuales, la sincronización se ha realizado mediante un **Token de Acceso Personal** con permisos de escritura (`repo`), asegurando un flujo de trabajo profesional y seguro.
